# JoJo: Gacha

JoJo:Gacha - это расширение для **SillyTavern**. Оно превращает чат в мини-игру по «Невероятным приключениям ДжоДжо»: за сообщения вы получаете **Стрелы**, выбиваете **Стенды** с анимациями, собираете коллекцию и «призываете» стенды в ролевую игру — Таверна узнаёт их характеристики и способности и отыгрывает по правилам.

---

## 1.1. Установка

1. Папку `jojo-stands/` (внутри: `index.js`, `animations.js`, `style.css`, `manifest.json`, `stands.json`, `img/`, `sounds/`) положить в папку расширений SillyTavern (`public/scripts/extensions/third-party/` или `data/<пользователь>/extensions/`).
2. Перезагрузить Таверну.
3. Открыть интерфейс: меню расширений (волшебная палочка) → **JoJo: Gacha**, либо настройки расширений → **JoJo: Gacha**

## 1.2 Установка

1. Перейдите во вкладку расширения.
2. Выберете вкладку `Instal extensions` и вставьте ссылку "https://github.com/Lopersigmula/JoJo-Gacha"
3.Перезагрузить Таверну.
4. Открыть интерфейс: меню расширений (волшебная палочка) → **JoJo: Gacha**, либо настройки расширений → **JoJo: Gacha**

## 2. Как это работает

### Стрелы 🏹
- Новый игрок получает **3 стрелы**.
- **1 стрела за каждые 5 сообщений**, отправленных вами в чате (при получении появляется уведомление).
- Игрок может сделать одну крутку и получить случайный стенд. После чего игрок может использовать стенд в Таверне, данные о способностях стенда автоматически подтягиваются из файла stand.json

### Шансы
По умолчанию (относительные веса): **редкий 90%, эпический 9%, легендарный 1%**.

Гарантии:
- эпик раз в 10 круток;
- легендарный раз в 50 круток.

### Источник стендов
- **Встроенный пул** — стенды из `stands.json` (98 штук: 58 редких, 28 эпических, 12 легендарных).
- **Генерация LLM** — стенд придумывает модель через `generateQuietPrompt`.

### Вкладки окна
- **🎲 Гача** — баннер, шкалы гарантий, кнопки выстрела, результат.
- **📖 Коллекция** — «Мои стенды» и «Все стенды» (весь пул по частям, неоткрытые закрыты 🔒).
- **⚙️ Настройки**.

### Карточка стенда
Название, тип, редкость, часть, шесть характеристик (power, speed, range, durability, precision, potential, ранги E–A) в виде шестиугольной диаграммы или списка, способность, ограничения, характер. Страница всегда открывается с самого начала. Кнопки:
- **Призвать в этом чате / Убрать из чата** — включает стенд в ролевую игру;
- **Загрузить фото снова** — повторная загрузка иконки;
- **Отказаться от Стенда** — убирает стенд из коллекции (с подтверждением).

### Влияние на ролевую игру
Призванные стенды добавляются в промпт Таверны (через `setExtensionPrompt`): общие правила стендов, ранги A–E, дальность, расход энергии и данные каждого стенда (характеристики, способность, ограничения, характер, текущая энергия). Данные о призванных стендах и энергии хранятся **отдельно для каждого чата**.

## 3. Анимации выпадения

У стендов с особой анимацией при выпадении играет своя сцена (надпись со звуком, затем эффект, затем результат). Остальные выпадают с общей анимацией. Всего 16 анимаций:

| Редкость | Стенды |
|---|---|
| Легендарные | The World, Dirty Deeds Done Dirt Cheap, Star Platinum, Heaven's Door, Killer Queen, Soft & Wet, King Crimson, Gold Experience, C-MOON, Made in Heaven |
| Эпические | Cream, The Hand, Silver Chariot, Magician's Red, Hierophant Green, Metallica |

---

## 4. Настройки

Всегда видны:
- включение системы стендов;
- источник стендов (пул / LLM);
- перечитать `stands.json`;
- откуда брать текст для страниц Heaven's Door («Код Таверны» или «Сообщения из чата»);
- «🗑 Удалить данные о картинках» (файлы из `img/` остаются);
- «Сбросить всё» (коллекция, стрелы и настройки).

## 5. Свои стенды и данные

Каждая запись в `stands.json`:

```json
{
  "id": "heavens-door",
  "name": "Heaven's Door",
  "rarity": "legendary",
  "type": "Ближнего действия",
  "icon": "img/heavens-door.png",
  "part": "Diamond is Unbreakable",
  "stats": { "power": "E", "speed": "B", "range": "C", "durability": "B", "precision": "A", "potential": "C" },
  "ability": "…", "limits": "…", "personality": "…"
}
```

- `rarity`: `rare`, `epic` или `legendary` Стенд с неизвестной редкостью отбрасывается.
- `icon`: ссылка `https://…` или путь к файлу в папке расширения (`img/…`).
- Анимация привязывается по `id` (или по имени карты). Стенду без анимации достаточно записи в json — код менять не нужно.
- Дубли `id`: побеждает последняя запись.
- Ранги в `stats`: `E`, `D`, `C`, `B`, `A` (неизвестные превращаются в `C`).
