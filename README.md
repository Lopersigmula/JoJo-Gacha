# JoJo: Gacha

Расширение для **SillyTavern** (версия в manifest: 2.41.0). Превращает чат в мини-игру по «Невероятным приключениям ДжоДжо»: за сообщения вы получаете **Стрелы**, выбиваете **Стенды** с анимациями, собираете коллекцию и «призываете» стенды в ролевую игру — Таверна узнаёт их характеристики и способности и отыгрывает по правилам.

---

## 1. Установка

1. Папку `jojo-stands/` (внутри: `index.js`, `animations.js`, `style.css`, `manifest.json`, `stands.json`, `img/`, `sounds/`) положить в папку расширений SillyTavern (`public/scripts/extensions/third-party/` или `data/<пользователь>/extensions/`).
2. Перезагрузить Таверну.
3. Открыть интерфейс: меню расширений (волшебная палочка) → **JoJo: Gacha**, либо настройки расширений → **JoJo: Gacha** → «Открыть интерфейс стендов».

Особенности: `index.js` загружается как ES-модуль и подключает `animations.js`; манифест принимает только один CSS-файл, поэтому весь стиль лежит в `style.css`.

---

## 2. Как это работает

### Стрелы 🏹
- Новый игрок (когда нет сохранённых данных) получает **3 стрелы**.
- **1 стрела за каждые 5 сообщений**, отправленных вами в чате (при получении появляется уведомление).
- Ежедневной бесплатной стрелы нет.
- Выстрел ×1 стоит 1 стрелу, выстрел ×10 — 10 стрел.

### Шансы
По умолчанию (относительные веса): **редкий 90%, эпический 9%, легендарный 1%** (обычные — 0).

Гарантии (по умолчанию):
- эпик (или выше) не позже чем через **10** круток без эпика;
- легендарный не позже чем через **50** круток без легендарного.

### Источник стендов
- **Встроенный пул** — стенды из `stands.json` (98 штук: 58 редких, 28 эпических, 12 легендарных; части Stardust Crusaders, Diamond is Unbreakable, Golden Wind, Stone Ocean, Steel Ball Run, JoJolion).
- **Генерация LLM** — стенд придумывает модель через `generateQuietPrompt`.

Если выпал стенд, который уже есть, счётчик копий (`copies`) растёт.

### Вкладки окна
- **🎲 Гача** — баннер, шкалы гарантий, кнопки выстрела, результат.
- **📖 Коллекция** — «Мои стенды» и «Все стенды» (весь пул по частям, неоткрытые закрыты 🔒).
- **⚙️ Настройки**.

### Карточка стенда
Название, тип, редкость, часть, шесть характеристик (power, speed, range, durability, precision, potential, ранги E–A) в виде шестиугольной диаграммы или списка, способность, ограничения, характер. Страница всегда открывается с самого начала. Кнопки:
- **Призвать в этом чате / Убрать из чата** — включает стенд в ролевую игру;
- шкала **энергии** (−10 / +10 / полная) — для призванных стендов;
- **Загрузить фото снова** — повторная загрузка иконки;
- **Отказаться от Стенда** — убирает стенд из коллекции (с подтверждением).

### Влияние на ролевую игру
Призванные стенды добавляются в промпт Таверны (через `setExtensionPrompt`): общие правила стендов, ранги A–E, дальность, расход энергии и данные каждого стенда (характеристики, способность, ограничения, характер, текущая энергия). Данные о призванных стендах и энергии хранятся **отдельно для каждого чата**.

## 3. Анимации выпадения

У стендов с особой анимацией при выпадении играет своя сцена (надпись со звуком, затем эффект, затем результат). Остальные выпадают с общей анимацией. Всего 16 анимаций:

| Редкость | Стенды |
|---|---|
| Легендарные | The World, Dirty Deeds Done Dirt Cheap, Star Platinum, Heaven's Door, Killer Queen, Soft & Wet, King Crimson, Gold Experience, C-MOON, Made in Heaven |
| Эпические | Cream, The Hand, Silver Chariot, Magician's Red, Hierophant Green, Metallica |

На время надписи у некоторых анимаций за текстом появляется полупрозрачная цветная подложка: у The World — жёлтая, у Star Platinum — фиолетовая, у Silver Chariot — серая, у остальных — свой фон.

Многие эффекты считаются WebGL-шейдерами; если WebGL недоступен, есть запасные CSS/2D-варианты. Во время анимации нажатия блокируются.

Кэш подготовки (настройка «animCache», включён по умолчанию) заранее грузит звуки и тяжёлые данные, чтобы анимации стартовали быстрее.

## 4. Настройки

Всегда видны:
- включение системы стендов;
- источник стендов (пул / LLM);
- перечитать `stands.json`;
- откуда брать текст для страниц Heaven's Door («Код Таверны» или «Сообщения из чата»);
- «🗑 Удалить данные о картинках» (файлы из `img/` остаются);
- «Сбросить всё» (коллекция, стрелы и настройки).

### Скрытый режим разработчика
Включается и выключается **5 нажатиями подряд на вкладку «⚙️ Настройки»** (пауза между нажатиями не больше 1,5 с). При каждом запуске Таверны режим выключен, состояние нигде не сохраняется. Пока он включён, появляются:
- в «Гаче» — панель DEV: выбить любую карточку без траты стрел и без влияния на гарантии;
- в «Настройках» — разделы «Стрелы» (сообщений за стрелу, +10 / +100 стрел), «Шансы» (веса редкостей и гарантии), «Анимации (просмотр)» (кнопки предпросмотра любой анимации).

## 5. Свои стенды и данные

Каждая запись в `stands.json`:

```json
{
  "id": "heavens-door",
  "name": "Heaven's Door",
  "rarity": "legendary",
  "type": "Ближнего действия",
  "icon": "img/heavens-door.png",
  "part": "Diamond is Unbreakable",
  "stats": { "power": "E", "speed": "B", "range": "C", "durability": "B", "precision": "A", "potential": "C" },
  "ability": "…", "limits": "…", "personality": "…"
}
```

- `rarity`: `rare`, `epic` или `legendary` (`common` допустим, но по умолчанию его шанс 0). Стенд с неизвестной редкостью отбрасывается.
- `icon`: ссылка `https://…` или путь к файлу в папке расширения (`img/…`). Локальные файлы надёжнее: не зависят от интернета.
- Анимация привязывается по `id` (или по имени карты). Стенду без анимации достаточно записи в json — код менять не нужно.
- Дубли `id`: побеждает последняя запись.
- Ранги в `stats`: `E`, `D`, `C`, `B`, `A` (неизвестные превращаются в `C`).

Настройки хранятся в `extensionSettings.jojo_stands`, данные чата — в метаданных чата. Значения по умолчанию подставляются только для отсутствующих ключей: у уже играющего пользователя остаются прежние шансы, число стрел и т.д. Новые значения увидит новый профиль или тот, кто нажмёт «Сбросить всё».

## 6. Звуки и картинки

- `sounds/*.mp3` — голоса и эффекты анимаций; подробности по каждому файлу — в `sounds/README.txt` (там слова «в index.js» устарели: тайминги теперь в `animations.js`). Большинство файлов необязательны: без них звук синтезируется кодом или анимация идёт молча.
- `img/` — локальные картинки: `killer-queen.webp` (внутри глаза Killer Queen), `soft-and-wet.webp`, `heavens-door.png`, `d4c.webp` (иконки; в `stands.json` у этих стендов `icon` указывает на файлы из `img/`). Иконка D4C также показывается на плитках в его анимации выпадения.

## 7. Структура папки

| Файл | Назначение |
|---|---|
| `manifest.json` | Описание расширения (`index.js`, `style.css`, порядок загрузки 20) |
| `index.js` | Данные, гача, интерфейс, настройки, промпт для ролевой игры |
| `animations.js` | Все анимации, звуки, кэш подготовки (`createAnimations(env)`) |
| `style.css` | Стили окна и всех анимаций (префиксы `jg-…`) |
| `stands.json` | Пул стендов |
| `img/`, `sounds/` | Картинки и звуки |

Для разработки есть отдельная памятка `JOJO-STANDS-MAP.md` с картой функций, таймингов и историей правок.

---

## 8. Ограничения

- Расширение писалось и проверялось без запуска настоящей Таверны (статические проверки и тесты в headless-браузере); основная целевая платформа — телефон на Android, интерфейс mobile-first.
- Тяжёлые WebGL-анимации на слабых устройствах могут тормозить; параметры для подбора описаны в карте проекта.
- Иконки из интернета (в основном вики) могут не загрузиться; после 5 неудачных попыток показывается эмодзи по типу стенда.
